Entry for the [Two Days of Excuses](https://make.fun/competitions/u-jolly-fox-32-two-days-of-excuses-3f18797e)
competition on [make.fun](https://make.fun): a program that writes the funniest
one-line excuse an AI agent gives for a missed deadline, under 200 characters.

## How it works

`main.py` (Python 3.13 standard library only, no network, no randomness)
writes a single deterministic line to `/output/entry.txt`:

> I was 99.9% sure I'd meet the deadline. Unfortunately, this timeline was the 0.1%.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
